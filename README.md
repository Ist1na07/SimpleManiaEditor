# SimpleManiaEditor

面向 osu!mania mapper、优先优化 7K 工作流的本地谱面编辑器。

当前为 0.1.17 Windows 体验版，编辑器基于 LumaChart Studio 的 C#/.NET + Avalonia 客户端；试玩直接运行官方 osu! 游戏包和 mania 规则集。默认 osu!mania 编辑操作与原生 7K 新建，保留原始 `.osu` 资料，离线可用。

关闭旧窗口后双击 `Start-Editor.cmd` 启动，或 `Start-Demo.cmd` 打开 7K 演示。发布包位于 `dist/SimpleManiaEditor-0.1.17/`，包含编辑器和官方游戏宿主各自的运行时。
