# SimpleManiaEditor

A local Windows osu!mania chart editor focused on 7K mapping, derived from LumaChart Studio. Official osu!lazer gameplay components run in an isolated playtest host.

Project, downloads and feedback: https://github.com/Ist1na07/SimpleManiaEditor

See the repository-root README and docs/FEATURES.md for current functionality and build instructions. Historical upstream mobile/support documents remain for reference, not as supported distributions of this fork.
