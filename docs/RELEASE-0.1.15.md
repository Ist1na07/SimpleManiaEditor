# 0.1.15：试玩暂停、独立倍率、吸附与原生 Timing

- Esc 在播放中或官方暂停面板中直接返回编辑器；Shift 打开官方暂停面板，再按继续。修复之前 Content 级快捷键被官方全局 Back 抢先处理的问题：实际输入和测试输入都先经过同一 PracticeInputManager，再进入官方队列。自动演奏也可以使用暂停面板。
- 试玩按钮右侧新增独立倍速下拉框，默认 1x，持久保存并提供非默认值复原；编辑播放倍率与试玩倍率互不改变。试玩保持音高。
- 右下角网格滑条移除 1/5、1/7、1/9、1/10、1/64；这些仍可在顶部网格下拉框选择。缩放刻度改为 0.1、0.25、0.5、1、2、4、8、16、32x，最高 4480 DIP/beat。
- 原生 `.osu` 允许在 Offset 之前放置、显示和移动按键，保存维持实际时间。顶部、左侧的撤销/重做到达历史边界时禁用变灰，草稿轨及 hitsound 轨使用各自正确的历史对象。
- 默认开启「全部吸附」：拖动选区按鼠标目标吸附，预览与提交使用相同规则；导入的大分母不再阻止移动。此前已用更细网格写入的分度仍保留，粗网格不会把短 LN 压成单键；单纯改变网格不会改谱。关闭后移动保留相对位置，过大的公分母使用误差不超过半微拍的有界表达。
- Timing Edit 的原生红/绿线采用独立新增/编辑弹窗。时间精度 1 ms，BPM 保留有效小数；支持 SV、节拍数、采样组、采样编号、事件音量和 Kiai。取消草稿不修改谱面，应用是一个撤销步骤，已有音符维持原始毫秒位置。
- BPM / Offset 输入旁直接显示「应用」按钮；`.osu` 的 Offset 显示 beat 0 的歌曲时间，内部 Malody Delay 的符号转换仅发生在界面边界。清理浮点尾数和负零显示；未编辑的原文件小数仍按原生保真策略保留。
- 设置新增明确的「音量与音频」区域。显示与字体缩放并入「编辑器设置 → 外观」；快捷键也收为默认折叠面板。调整卡片默认锚定编辑区右下角，避免遮住 Timing/设置侧栏，仍可拖动。
