# 0.1.9 全屏试玩、osu!mania 皮肤与键位导入

用户允许界面和落速采用 lazer 风格。本版保留已有 stable ScoreV1 兼容判定，采用独立全屏游戏画面与 lazer 的落速定义，没有嵌入完整 osu! 客户端。

- 绘制单键和 LN 时，按住鼠标不再隐藏跟随预览；鼠标底边时间锚点和最近网格吸附保持原逻辑。
- 默认全屏试玩。游戏过程中隐藏编辑工具栏和设置面板，显示分数、准确率、连击、判定、误差条和进度；支持谱面背景。Esc 暂停/继续，F1 设置，F11 全屏/窗口，Ctrl+R 重试，暂停菜单可返回编辑器。设置叠在游戏上，不缩窄或重排轨道；丢失窗口焦点会暂停并释放按键。试玩结束显示本次统计。
- 导入皮肤目录或 `.osk`，按当前 K 数选择 `[Mania]`。支持自定义子目录、PNG/JPEG、`@2x`、连续动画帧、Note/Head/Body/Tail、Key/KeyD、StageLeft/Right/Bottom/Hint/Light、LightingN/L、六档判定、ComboBurst、数字字体和暂停菜单素材。
- 支持列宽/间距/分隔线/颜色、ColumnStart、HitPosition、ComboPosition、ScorePosition、WidthForNoteHeightScale、KeysUnderNotes、UpsideDown、翻转开关、SpecialStyle、SplitStages/StageSeparation，以及拉伸/平铺面身。列光颜色在后台预生成，命中光使用加法混合。缺图逐项回退；皮肤控制的尺寸/样式滑条会禁用，防止空操作。可重新加载修改过的皮肤。
- 皮肤 `normal-hitnormal.wav/ogg/mp3` 预解码并复用现有低延迟输出；可切换皮肤声音。未提供该样本时，使用编辑器已有按键音设定。
- 从 `osu!.用户名.cfg` 导入各 K 数的 `ManiaLayouts#K`、落速、当前本地皮肤、升降速/暂停/重试快捷键与皮肤声音开关。兼容常见 WinForms 键名别名；拒绝未知/重复键位并保留原设置。另提供导入皮肤旧式 `Key0…` 的按钮。绑定 Enter/Space 时按轨道输入处理，优先于播放快捷键。原始 cfg 与账号信息不保存、不上传，osu 原件不写入。
- 落速 1–40，可按 0.1 调整；默认 F3 加速、F4 减速，Ctrl/Shift 加减号也可调整。`TimeRange = 11485 / speed` ms，按 480 高度下默认 HitPosition=402 转换画面速度，随分辨率等比缩放。自定义判定线不会偷偷改变基准速度。谱面 BPM/SV 沿用连续积分，音频倍率保留既有滚动补偿。旧版自定义方案继续保留 px/s。旧 stable 的 BPM 落速缩放不冒充 lazer 等价设置，导入时明确提示。

导入会检查包内路径、文件数量、解压大小和解码像素预算；失败的临时导入目录清理，成功素材保存在本应用数据目录。皮肤原目录可直接读取，换肤释放旧纹理；渲染和键盘输入不读取文件。100k 音符继续使用单控件、二分/区间裁剪。

具体使用与兼容边界见 `PLAYTEST.md`。完整 HP/失败、Mods、回放和谱面采样组/附加音仍未实现；暂停/结果页面为本项目游戏界面，不能称为完整 lazer 客户端。没有重分发用户皮肤或官方游戏美术素材。

验证：50 项核心回归、真实 Avalonia 键鼠/布局/Skia 渲染、HD/动画/字体/颜色/皮肤声音、配置隐私与无效布局、归档越界保护、全屏与暂停操作、100k 皮肤裁剪，以及最终便携包解压启动。真实设备输入延迟和具体第三方皮肤视觉仍由 mapper 验收。
