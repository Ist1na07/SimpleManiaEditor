# 0.1.14：试玩快捷键、自由平移与选项控制

- 试玩默认用左右 Shift 暂停/继续，按住不会重复切换；Esc 直接返回编辑器。练习快捷键位于 replay/ruleset 输入之前，自动演奏和暂停状态也可使用。Ctrl+P 保留为兼容操作，Tab 自动演奏与 Ctrl+O 官方设置保留。
- 底板左右各留出一屏空白，即使轨道总宽小于视口也可平移；拖到任一端可以把全部轨道移出画面。窗口尺寸变化时保持当前平移关系，新增轨道不主动跳转。
- 下拉选择框、调整卡片和设置滑条支持滚轮；向上增加、向下减少。底部滚动条滚轮控制水平平移，控件上的滚轮不会同时滚动谱面时间。
- 编辑器的视图、显示缩放、网格/倍速、备份、声音、操作方案与快捷键提供逐项「↶」恢复默认值。只有值偏离默认时显示；恢复使用出厂值，非启动时读到的已保存值。快捷键冲突按既有绑定规则处理。文档数字字段仍需点击「应用谱面信息」提交。
- 「编辑器设置」的外观选项合并为默认收起的「外观」，编辑器皮肤也移入这里。
- 「谱面」页补上 OD、HP 的可见编辑入口（0–10），支持滚轮微调、恢复默认值、原子应用、撤销与原生 `.osu` 读写。无效输入拒绝整个提交，避免仅应用另一项。
- 更新 BACKLOG：区分已实现的基础编辑/难度属性、只保留源字段但没有编辑入口的官方选项，以及完整 hitsound/SV/故事板等剩余工作。

验证包括编辑器指针、滚轮、选项默认值/显示状态、空白底板边界、OD/HP 原子修改与原生读写；真实官方 GPU 宿主通过输入队列验证 Shift 按住/继续和 Esc 返回，并连续三次自动演奏、重进与设置页面。设备手感仍由真实体验验收。

关闭旧编辑器后运行根目录 `Start-Editor.cmd`；便携包在 `dist/SimpleManiaEditor-0.1.14/`。
