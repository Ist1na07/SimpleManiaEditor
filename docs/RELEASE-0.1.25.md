# SimpleManiaEditor 0.1.25

- 修复非零音画校准下，小幅向前滚轮跳转失效：从显示时间逆变换到音频时间，跳转完成后重置显示时钟并跳过旧缓存；恢复播放也读取新时钟。连续暂停/跳转压力测试中的请求挂起也已修复，提交不再依赖循环界面定时器。播放滚轮和同步草稿时间转换使用高精度。
- 0.1x 不变调处理优化：四阶段音高恢复保留，缩短仅用于极低速的处理窗口，减少预热和持续 CPU 占用。48kHz 双声道测试预热由约204ms降至25–50ms，1秒输出处理从约637ms降至196–350ms；这些是本机DSP测试，不是所有设备的延迟保证，真实音乐的音质和设备体验需验收。
- 设置 → 音频增加音画校准器。每1200ms短音与光点穿过中心线对齐，支持±1/±10ms和滑条调节，Space试听/暂停；使用才保存，取消不改设置。打开前停止编辑器声音，关闭时等待停止输出并清理私有临时音频。用眼耳反复校准，避免点拍反应时间影响，不宣称自动测量1ms精度。
- Note文本代码区直接展开，主按钮“应用”按代码原始时间添加音符；属性按钮移到属性区并标为“应用属性”。Ctrl+C仍写入可分享的osu HitObjects文本。
- Ctrl+V 改为虚影放置：先预览、跟随鼠标和网格吸附，未占满键数的排列允许左右移动；可跨主轨与草稿轨，也可直接在鼠标所在草稿轨开始粘贴。单击提交、Esc/右键取消，单次撤销；保持相对拍、LN长度、采样信息，锁定范围预检，相同物件不重复加入。取消不会删除下面的音符。
- 草稿“放入主轨”按原歌曲毫秒时间对齐，不使用播放位置；原草稿保留，重复转入相同物件跳过。对照轨转入保留排列和时间，移除原歌曲专属采样引用。新增草稿“清空”，可以撤销。
- 新旧草稿继承osu负拍信息，修复无法滚动/编辑到Offset前的格式限制。Alt+滚轮在同步草稿中同步缩放，非同步草稿仅调整自身；Ctrl/Shift网格与倍速操作继续可用。

验证：59项核心规格、完整界面回归（包含真实解码/DSP＋模拟音频输出）；覆盖音高/连续输出、校准跳转和0.1x暂停继续、虚影跟随/跨轨/点击/取消/撤销、三连音有理数精度、草稿时间对齐/去重/清空、负拍/Alt滚轮、文本应用，以及校准器试听/Space不误触应用/取消/确认/输出隔离/临时文件清理。便携包另做启动、7K/LN读写检查。本版官方游戏宿主仅更新版本号。
