# 0.1.26 音频与多轨同步验证

2026-10-13，本地Release构建。以下都是处理及模拟输出基准，未测声卡、屏幕或扬声器的端到端延迟。

## 音质回归

旧极慢链路先线性放慢，再串联3/4段SMB恢复音高，每段独立处理左右声道并限幅。0.1.25为了降低开销缩短分析窗口，单440Hz测试未能暴露复杂频谱失真。独立旧版对照的双声道三音和弦中，主音附近±8Hz以外的能量约左43%/右76%，输出峰值也高于输入。

0.1.26统一单阶段SoundTouch的联动双声道时间伸缩。正式Audio026Specs使用48kHz已知三音和弦、8192点Hann FFT，在三音附近两个FFT频点以外的能量实测约0.05%–0.08%。这项指标只衡量可计算的稳态刺激，不给任意音乐做音质评分。

覆盖0.1/0.25/0.5/0.75/0.9/1/1.1/1.25/1.5/2x，单/双声道；另测扫频、非谐波和短噪声打击、同声道一致性和单侧静音。512/2048/8192样本读块及未预热参考逐样本相等；没有丢失首段脉冲、声道泄漏、非有限值或错误尾部时长。48k双声道0.1x两秒输入/二十秒输出的处理约0.58–0.68秒，热态准备首块约6.5–9.3ms；首次JIT冷启动可能更慢，不代表每台设备表现。

## 跳转与连续输出

生成20秒48k双声道音频：左右分别叠加440/997Hz、550/1373Hz与不同扫频；用PCM WAV、MP3和Ogg三种格式。5ms模拟消费端读取真实解码及DSP。每个格式/倍率8次跳转，随后低于0.3x连续播放2秒，其余500ms，避免只统计预热缓存；没有新增输出设备、意外停止或暂时空音频块。33组、264次跳转均通过。

## 多轨同步

两条草稿（同步与独立）、局部密度、波形与频谱的500帧测试：逐帧轻量同步500次、完整布局同步0次；不同BPM/offset仍按歌曲毫秒对齐，独立轨不动。网格/皮肤配置变化、缩放及暂停仍更新相关状态。

同条件直接调用同步方法500次，轻量约0.36–0.41ms、完整约1.02–1.03ms。它仅说明减少了同步方法的重复工作，不含实际绘制和GPU Present，不能据此宣称稳定180fps或1%low180。硬件验收仍在未完成清单中。
