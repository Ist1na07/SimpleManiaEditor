# 0.1.11：官方 osu!mania 试玩宿主

- 网格、缩放、倍速刻度滑条移到右下角可移动卡片；拖动标题移动，位置/折叠状态保存，窗口缩小时限制在可见范围。顶部命令与下拉预设为单行。
- 编辑器「试玩」直接运行官方 `ppy.osu.Game` 和 mania 规则包 2026.916.0；官方 Player、皮肤导入/选择、游戏设置、LN 绘制、判定素材、音频时钟与采样接管实际游戏。旧 Avalonia 试玩渲染器不再从编辑器启动。
- 使用独立游戏窗口/进程和本应用的 `osu-host` 数据目录。关闭/退出试玩回到编辑器，不连接已安装的 osu! 进程，不覆盖 Songs、原皮肤或 osu! 配置。
- 试玩导出已提交的当前编辑状态为临时 `.osz`，保留原音频、timing/SV 与资源；未保存到原件的编辑也能测试。从当前时间启动，起点以前的音符只从测试副本移除。
- 首次启动迁移旧试玩的皮肤、普通 1–10K 键位、落速/方向与 offset；后续采用官方持久化设置，不用旧编辑器配置覆盖。显式 cfg 导入会在下一次试玩应用一次。
- 顶部试玩按钮右键可导入皮肤目录、Skins 目录、`.osk` 或 osu! 用户 cfg；皮肤包交给官方导入器。已登记的本机四份皮肤已在隔离测试目录导入，未分发用户皮肤。
- 游戏中 Ctrl+O 打开完整官方设置；Tab 切换自动演奏，Ctrl+P 快速暂停；Esc 菜单、F3/F4 落速、Ctrl+R 重试沿用官方行为。
- 覆盖官方导入任务的归档删除行为，保留用户包文件。修复中途自动演奏截取丢失初始空状态而漏判起点音符的问题。

判定/计分现在采用实际 lazer mania；不再将自制 stable 兼容判定和自制皮肤绘制混用。练习不失败、不记录或上传成绩。初次游戏启动含字体/着色器/皮肤导入，可能比旧轻量试玩慢。

验证包括核心 50 套、编辑器 headless 回归（实际卡片拖动、三滑条/预设同步、工作副本交接），以及 Windows 官方 GPU 游戏集成：本机 Wilben_Chan v2、7K LN、完美自动演奏、0.25x/中途启动、原包保留、官方皮肤下拉绑定与重进持久化。真实键盘/音频设备延迟仍由用户验收。
