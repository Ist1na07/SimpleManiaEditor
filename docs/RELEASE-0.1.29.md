# 0.1.29 · 曲库快捷编辑与 GitHub

曲库谱面行支持双击打开编辑，右侧按钮继续可用。只有一个匹配难度时，双击曲目卡片直接进入该谱面；多个难度时展开列表供选择。虚拟化卡片复用后仍打开当前谱面，打开过程中重复操作合并。来自只读库的谱面继续通过创作副本编辑。

通用设置和关于页统一显示SimpleManiaEditor与0.1.29，移除上游B站、赞助及内容后台入口。GitHub仓库与问题反馈入口指向本项目；反馈不自动附加谱面、路径或日志。

点击检查更新读取本项目GitHub正式Release，只接受本仓库HTTPS Windows x64 ZIP下载地址。新版本可打开浏览器下载，完整解压到新目录后启动；不会自动安装或改写谱面。无Release、离线、请求受限等显示具体状态和手动发布页入口，正常编辑不依赖联网。

源代码MIT许可证新增Ist1na署名，同时保留LumaChart上游版权。官方游戏资源、音频库、字体及其他依赖的独立许可证继续随分发包提供。

验证包含曲库双击与卡片复用、多难度选择、防重复打开、版本比较、无发布版本、下载来源校验、请求不发送凭据或本地数据、关于与设置品牌；核心及完整UI回归。实际游戏手感和设备播放性能未在本轮改变。
