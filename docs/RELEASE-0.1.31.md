# SimpleManiaEditor 0.1.31

本轮围绕 mapper 的「收集参考 → 整理待发布作品 → 往返 Songs → 测图前留稿 → 对照恢复」工作流。

- 曲库加入 SQLite/FTS 持久化索引、缓存头部、文件变化监听和后台组合搜索。收藏、标签、发布状态、备注在个人库中保存，不写进 .osu；支持单张和批量整理，顶部直达收藏与未发布筛选。
- 复制或迁移整套 mapset 前显示文件清单、体积与目标。默认保留源文件，重名新建；显式移动保留源备份。涉及 Songs 要求关闭 osu!。持久化事务支持中断回退，检测到新修改会停止清理。
- 内置真实 Git，无需安装 Git。保存时自动快照，也可创建命名版本并记录资源。历史列表和共同毫秒轴展示音符/LN差异，列出 Timing/元数据变化；恢复前留稿、Ctrl+Z 撤销，旧资源可导出到独立新目录。

入口：点击左上角品牌进入曲库，在难度行点「整理 / 迁移」；迁移恢复在曲库顶部「迁移记录」；编辑顶部「版本历史」。详细流程见 [曲库与版本说明](https://github.com/Ist1na07/SimpleManiaEditor/blob/main/docs/LIBRARY-VERSIONS.md)。

5 万个实际生成文件：冷扫描与写索引约 21.7 秒，已载入缓存后扫描约 2.2 秒且不重解析头部。20 万条索引：典型曲名组合约 15 ms，返回 20 万结果的宽泛作者搜索约 1.4 秒，在后台执行。这些是隔离生成素材基准，不是用户真实 Songs 或网络盘的保证。

当前版本历史是文档快照；逐命令持久日志、分支合并、远程同步、完整音效/草稿语义 diff 仍待做。迁移备份暂不自动清理，也未完成真实断电验收。旧有音频和高刷新率表现仍需实机确认。

Windows x64 分发包自带编辑器、官方试玩宿主及运行时；完整解压后双击 Start-Editor.cmd。包内不含个人谱面、音乐、皮肤、设置、Git 历史或数据库。
