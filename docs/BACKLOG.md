- 原生 7K 新建、`.osu` 打开/保存、音符和 BPM 编辑、复制粘贴、框选、移动、撤销重做、LN 正反向绘制。

- osu 默认键鼠方案、可改快捷键、左侧工具与快捷编辑、固定顶部命令/下拉选项、带刻度的调整滑条、当前位置一键启动试玩。

- 0.1x～2x 编辑播放、0.25x～1.5x 独立试玩预设，试玩保音高、编辑可选保音高；普通跳转复用设备，慢倍率 DSP 后台准备。
- 保存前备份、外部修改检查、约 2 秒恢复 checkpoint；原生 osu 源资料保留；生成音频的演示谱面与便携构建。

- 可见 OD/HP 编辑（0–10）、原子应用与撤销、原生 `.osu` 保存；试玩 Shift 暂停/继续、Esc 直接返回。

- 试玩期间立即中断编辑播放并锁定编辑区，返回保持暂停；Timing 仅选中后明确删除；底部毫秒时间轴、BPM/SV 事件线、Kiai 高亮、书签与点击定位/双击编辑。
- 固定且可隐藏的全局密度/难度；可添加的局部密度/实验性难度轨使用滑动窗口连续绘制并随主轨同步。官方/Sunny 7K 难度算法仍待做；撕裂处理采用系统合成，待实机验收。
- 原生毫秒 Timing 新增/编辑弹窗，BPM/SV、Kiai、事件音量/采样组/编号可编辑和恢复；原生 Offset 前按键，默认全部吸附、细分保护、批量偏移和撤销边界。

- 0.1.17 修复普通 checkpoint 指纹不同步；旧版有效脏副本保留、核对后另存为。顶部显示/布局可恢复全局栏、整理主轨；启动/缩放后底板定位稳定。播放中 UI 不回跳，合成帧视觉时钟吸收离散采样抖动，硬件流畅度待实机验收。
