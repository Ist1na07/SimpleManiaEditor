# 功能完成情况与未完成清单

更新基线：0.1.12。这里是当前状态，早期规划和旧发布说明保留当时的记录。

“部分”表示已有入口或上游基础，仍需补齐并验收；“待做”表示尚未提供完整的本项目工作流。所有项目最终仍由 mapper 在真实歌曲、音频设备和 osu! 中验收。

## 已交付的编辑体验

- 原生 7K 新建、`.osu` 打开/保存、音符和 BPM 编辑、复制粘贴、框选、移动、撤销重做、LN 正反向绘制。
- 单键只放单键，长条点击放单键/拖动绘 LN；osu 绘制工具左键替换、中键移动，整块 LN 尾调整；鼠标跟随预览、28 DIP 默认厚度、LN 尾与按键的重叠检查。
- osu 默认键鼠方案、可改快捷键、左侧工具与快捷编辑、固定顶部命令/下拉选项、带刻度的调整滑条、当前位置一键启动试玩。
- 暂停按网格滚动；播放按每格滚轮 500 ms 跳转并继续播放；Ctrl+滚轮跳过五/七/九/十分网格，全部预设可用滑条手动选择。
- 12～3840 DIP/beat 缩放；默认 osu 音符外观，保留 malody 外观；选择可持久化。
- 0.2x～2x 编辑播放与试玩，保音高开关；普通跳转复用设备，慢倍率 DSP 后台准备。
- 保存前备份、外部修改检查、约 2 秒恢复 checkpoint；原生 osu 源资料保留；生成音频的演示谱面与便携构建。
- osu/general 网格换算、Shift 倍速滚轮、独立草稿和只读对照轨、hitsound 文件/音量、密度/实验性负荷轨；独立轨道保存、隐藏和时间同步。
