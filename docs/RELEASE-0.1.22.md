# SimpleManiaEditor 0.1.22

- 每张谱面记住自定义轨道、顺序、宽度、底板左右平移和主轨播放位置；独立轨道记住视口及缩放。正常退出、关闭标签后重新打开会恢复；保存完成的手势，恢复时保持暂停。
- 修复编辑模式已经切换、选项框仍显示最小模式。界面翻译现在保留文字的数据绑定。
- 添加新音乐不自动测量 BPM / Offset；手动检测入口保留。Timing Edit 新增“将此处设为 Offset”，把当前歌曲时间设为首条红线时间，可撤销，已有音符的绝对歌曲时间保持不变。
- 新建 LN 和拖动面尾时连续跟随鼠标，松手才吸附最近格线。实际时间仍在按键底端，音符显示锚点不变。
- 修复 Timing 变更后导出仍复用旧时间行的问题。导入首红线以前有音符的谱面不再添加改变 offset 的虚拟 BPM 点，直接保留负拍。缓存、保存、导出及再次导入均有验证。
- 旧缓存中可识别、未修改的虚拟起始 BPM 会安全移除并保留绝对时间及音符属性；已经手动改过该旧事件的缓存保留原状，不推测用户意图。已经丢失的旧修改无法从文件中自动还原。
- 最小模式新建谱面的 Timing sample volume 为 0；音符使用继承值，编辑器键音试听保持独立。完整模式默认 70，不改已有谱面。
- 试玩加载期间与隐藏待机期间的按键不带入游戏，释放与重复输入成对处理。Windows 默认采用官方 SDL2 后端、关闭系统菜单键提示，避开上游 SDL3 无点击激活的焦点问题；参见 [官方问题记录](https://github.com/ppy/osu/issues/37902)。实际提示音是否完全消除仍需用户原环境确认。

验证：57 项核心规格通过；完整界面回归涵盖连续 LN 预览、松手吸附、真实模式显示、工作台保存/重开、Offset 设置/缓存/保存/导出、旧缓存迁移、最小模式 sample volume，以及原有音频、皮肤、轨道和快捷键流程。实际官方 GPU 宿主连续三次试玩通过，覆盖加载 Space、游玩 Space、Shift 暂停/继续、Esc 返回、重开、完整设置与关闭。便携包另做启动和原生 7K/LN 读写检查。

播放性能仍按 0.1.18 的实测限制记录，未声称达到稳定 180 FPS。
