核心设计有六点：

1. **实时编辑留在前端。** 放键、拖动、框选、滚动、播放和试玩不等待 Python 往返。Python 负责文件、持久化、索引和后台分析。
2. **所有谱面变更统一为 command。** 撤销、重做、编辑轨迹、恢复和版本比较共用操作协议。未来协作复用协议，再补充排序、冲突和断线恢复。
3. **兼容文件与创作资料分开。** `.osu` 保持游戏兼容；草稿轨道、备注、标签、历史放在公开可读的辅助文件中。索引和分析缓存可重建。
4. **保存可靠性从第一版开始建设。** 操作日志、刷盘确认、快照、文件替换和中断恢复先建立；界面区分待保存、恢复日志已持久化和 `.osu` 已保存。
5. **大库采用增量索引。** 首次优先读取元数据，音符分析、音频解码和难度按需执行；列表虚拟化。规模基准按五万 mapset、二十万 difficulty 设计。
6. **多轨道明确导出语义。** 草稿不会自动混入正式谱面；对照轨道可独立滚动；跨轨道粘贴处理 BPM、列映射、LN 和声音资源。
