# 0.1.7 绘制工具与鼠标预览

- 单键工具拖动保持单键。长条工具点按放单键，拖动到不同格线才生成 LN，支持正反向绘制。
- osu 方案的单键/长条工具左键命中已有按键时替换重画，中键拖动移动原按键或 LN；中键在空白处不平移轨道，其他工具仍保留中键平移。
- 左键点 LN 面尾的整个可见按键区域均调整长度；右键删除命中范围仍按可见按键计算。
- 绘制工具空闲时显示跟随鼠标的半透明按键，底部中心严格对应鼠标尖部；放置时仍按最近格线吸附。
- 默认按键厚度从 32 降至 28 DIP；迁移旧默认，保留其他自定义值。
- 同一轨道的单键或 LN 面头落在另一 LN 面尾时报告重叠，晚于面尾的按键不误报。草稿不进入正式谱面校验。

替换在按下时立即显示新按键预览，松开后删除与添加作为一个命令提交，可一次撤销恢复旧对象（含原 hitsound）。取消操作保留旧对象；检测期间的其他修改并取消过期提交，保护只读与锁定选区。

新增实际指针回归覆盖工具点按/拖动、整块面尾调整、中键移动/平移、替换撤销重做、只读保护和预览底边像素位置；核心校验覆盖尾部重叠和相邻合法时间。
