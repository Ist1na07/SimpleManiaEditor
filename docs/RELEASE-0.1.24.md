# SimpleManiaEditor 0.1.24

- Tap/LN选中与错误提示改为外形内部高光，不再向外扩张按键大小。
- 编辑器0.2x预设改为0.1x，实际播放、保存设置、滚轮与不变调处理全部支持0.1x。极低速使用四阶段音高恢复，原有0.2x/0.25x仍可作为连续滑条的值。试玩预设去掉0.2x和2x，保留0.25x、0.5x、0.75x、0.9x、1x、1.1x、1.25x、1.5x；旧越界试玩倍速恢复1x。
- 分类设置中的外观、快捷键默认展开，仍可手动折叠。
- 波形和频谱不再截掉第0拍之前的音频，按真实音频0ms至结束范围显示；负拍视口与主轨一致。背景可视化与侧轨共用修复。
- Timing Edit新增清晰的“将当前位置设为 Offset”按钮；Offset下方 << / < / > / >> 分别调整-10 / -1 / +1 / +10ms，立即应用、一键撤销，保留已有音符绝对时间和暂停的歌曲位置。
- 设置 → 音频增加“编辑器音画校准”，-500至500ms，默认0，非默认时有恢复按钮。正值画面提前，负值画面延后；独立保存，不改变谱面时间、编辑键音补偿或官方试玩。倍速下按真实时间校准，暂停/继续不会累计补偿。

偏差核验：已知起音237/475ms、120BPM、24秒衰减正弦节拍，在44.1kHz和48kHz PCM的完整能量/检测链中，预测分别240/480ms，偏差+3/+5ms。另12组合的合成能量测试偏差0至5ms。未证实普遍固定10ms，不添加固定10ms补偿。真实音乐的起音定义、压缩音频和实际设备仍需另外测量；全局音画校准不会改变自动BPM/Offset结果。

验证：58项核心规格、完整界面回归；实际0.1x DSP保持440Hz测试、Offset前波形/频谱、负拍视口、独立倍速预设、Offset按钮及微调撤销、全局校准保存/恢复和暂停继续逆变换。便携包另做启动及7K/LN读写检查。本版官方游戏宿主逻辑未修改。
