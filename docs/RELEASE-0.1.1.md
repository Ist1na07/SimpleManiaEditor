# 0.1.1：osu!editor 交互与音频启停修复

日期：2026-10-08（Asia/Taipei）。完整项目范围及尚未完成的高级功能延续 0.1.0。

## 修复

- 默认帧率上限改为 **1000 FPS**，与高频采样时钟阈值分开。旧版默认 165 设置首次迁移为 1000；新版显式选择的其他帧率保留。实际显示帧率仍受显示与渲染环境影响。
- 默认滚轮向下前进到更晚的时间；设置 → 快捷键增加独立的方向选项。切换 Luma legacy 会采用其原方向。
- **Ctrl+滚轮调整网格**，不会修改时间位置或缩放；Alt+滚轮仍缩放。网格下拉控件固定在编辑区顶部，与快捷键、调整浮窗和当前 tab 同步。
- 播放中滚轮跳转保持播放状态，不再主动暂停或使用 650 ms 续播抑制。快速连续跳转合并至最新目标，显式按 Space 暂停后不会被旧跳转重新续播。
- RC/单键工具允许从晚到早反向拖出 LN，开始/结束时间排序；前向拖动和单击单键行为保留。
- 右键删除只检测绘制实体，不再使用宽松的 LN 尾部调整范围；邻近 tap 优先于 LN 面身/面尾，保留可撤销删除。
- 音频输出增加 **5 ms、按采样帧执行的淡入淡出**，覆盖音乐与混合 hitsound。暂停/重建前等待淡出缓冲被消费，减少非零振幅突然截断造成的瞬态。

## 验证

- 软件回归覆盖默认帧率与迁移、方向选择及持久化、Ctrl 网格手势、反向 RC-LN、尾部区域误删和邻近键命中。
- 恒定立体声测试检查启停幅度连续性、两声道同步和恢复淡入。
- 完整窗口接入模拟输出端，消费真实 WAV 解码/DSP 数据，检查播放中跳转不调用 Pause、落在目标时间、Space 暂停不会被旧 seek 重新播放。
- 核心规格 **49/49 通过**，完整 UI smoke 与上述新回归通过；warnings-as-errors 构建零警告、零错误。

硬件设备上的噪声听感尚待用户复测；以上验证不等于所有驱动的端到端音频验收。

## 更新

关闭旧版窗口，再使用根目录 `Start-Editor.cmd` / `Start-Demo.cmd`。新包位于 `dist/SimpleManiaEditor-0.1.1/`；旧包与用户编辑过的旧演示文件保留。设置/工作副本仍在独立的 SimpleManiaEditor 用户目录。
