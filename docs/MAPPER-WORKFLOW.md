# 曲库、参考轨与排列库（0.1.35）

## 从游玩谱库找到值得研究的图

点击左上角 SimpleMania 图标进入曲库。左边是自己的作品工作区，也包含以前版本已收录的个人工作区，原文件不搬动；右边选择已经添加的只读曲库。点顶部「添加只读曲库」选择 osu! 的 Songs，后台建立索引；非 mania 谱面不列入，包括没有填写 Mode、实际属于 standard 的旧谱。第一次更新到本版会重建旧版本的曲库头信息索引，个人标签、备注、收藏和历史保持原样。

左右搜索独立；右侧可搜索标题、作者、难度，也支持已有的 `tag:LN`、`keys:7`、`star:true`、`note:第二段` 等索引语法。右侧只创建可见的行，不会为了显示曲库而解码每张谱面的音频或完整按键。

左边双击难度进入编辑。右边双击（或 Enter／「只读查看」）直接查看原件，可以播放、定位、框选、复制和提取排列；不能放置、移动、删除音符、改 Timing／元数据或保存原图。标签上的「只读」和左侧的「克隆并编辑」明确当前状态。重启后仍保持只读。

要改编原图，在曲库右边点「克隆到工作目录并编辑」，或在只读查看时点左侧「克隆并编辑」。复制整套难度和资源，校验后进入独立副本。重名会使用新目录，不合并覆盖。仅复制出 Songs 可以在游戏运行时进行；移动原图或写回 Songs 仍需退出游戏并走有预览和确认的事务流程。

## 在写图时添加参考

在底板空白处右击，选「从曲库添加参考谱面」，搜索工作目录或已索引的只读曲库，选好后添加。参考内容保存在编辑器自己的轨道快照中，不修改来源。

参考轨左边有密度时间索引，点击／拖动直接找段落；上面也可以输入毫秒，或 `分:秒`（如 `1:23.500`）后点「定位」。这些定位操作会取消与主轨的同步，让参考停在自己需要的位置。重新勾选「同步」即可回到共享音频时间滚动。参考轨可框选、复制，不能修改来源按键。

## 收集排列

1. 在只读谱面里用选择工具框出喜欢的按键。
2. 在底板空白处右击「添加排列库轨道」，再在该轨道上点「加入主轨选区」。可以像草稿一样用复制／粘贴向排列轨加入内容。
3. 排列轨独立可编辑，可去掉多余按键、移动、撤销或清空，原图保持只读。注意时序：它保留选取的原拍数位置，并非粘到当前播放位置。
4. 在排列轨点「保存排列」，看简洁形状预览、确认预填的歌曲／拍数名称或改名后保存。每次保存生成一份新排列，已有排列不被覆盖。文件是资料目录 `Patterns/*.json`，保存相对拍数和轨道，不包含音乐和绝对来源路径。

## 在另一首歌中使用

点左侧「排列与变换」中的「排列库」，滚动或搜索名称／来源。列表用同宽实心块显示单键和长条，便于辨认排列，不套用编辑器皮肤。

选中后点「取出排列」或双击，鼠标带着虚影回到编辑区。首个按键吸附当前网格，不占满所有列的排列可左右移动。默认一个来源拍对应一个目标拍，因此换 BPM 会自然改变绝对毫秒时长，而保留节奏关系。

- **直接放置**：单击。整份排列一次撤销／重做。
- **比例缩放**：Ctrl+滚轮，多级范围为 1/64–64 倍。仅在取出排列期间改变排列尺度；普通 Ctrl+滚轮仍调整网格。
- **指定时间范围**：虚影移到起点，按 Enter 固定；移动到希望的终点，再按 Enter（或单击）完成缩放并放置。虚影旁持续显示提示；空格始终用于播放／暂停音乐。
- **取消**：Esc 或右键。确定前不会写入按键。

可以把虚影移到可编辑草稿／排列轨放置。只读主轨和参考轨不接受放置；先克隆谱面即可编辑主轨。跨键数使用时按实际排列宽度检查，放不下时提示，不静默截断。

当前限制：尚无无歌曲的独立排列文档、库内重命名／删除及专门的分享入口。可读 JSON 已预留格式版本；无法读取的排列文件保留并跳过，不清空整个库。版本 diff 也改用同宽实心长条与单点；历史比较仍使用共享毫秒轴。

## 验证范围

合成流程覆盖只读权限和重启恢复、克隆后编辑、索引规则升级保留个人资料、跨 BPM 与七分拍的精确比例、虚影／起终点／滚轮缩放、取消和一次撤销、命名保存及库内再次放置、参考选取与索引。2 万行索引的分栏／布局／滚动测试约 350–390 ms，只实例化 15 个可见行。这是本机合成 UI 测试，不是用户真实 Songs 的冷扫描耗时或实机手感结论。

0.1.34 快照加载：启动时先显示本地索引，再在后台核对磁盘，返回曲库不重复全扫；手动「刷新索引」仍可强制核对。首次收录新 Songs 必须扫描，不承诺即时完成。只读查看不会要求提交侧栏格式化产生的假修改，切换、关闭及退出不再弹观察者权限提示。播放时按住框选，起点固定在音乐时间，鼠标端随播放继续扩展选区。

## 选区拉伸与工具分区（0.1.35）

选择、单键、长条、擦除只用于切换基本操作。剪切／复制等位于快捷编辑；中心对称、排列库和拉伸位于其下的「排列与变换」。没有常驻「放入排列轨」按钮；收录操作只出现在排列轨内。

框选按键后点「拉伸」。金色框内拖动可平移时间和轨道，上／下边拖动可改变对应时间边界，内部单键与 LN 两端按比例同步改变，另一边固定。拖动只预览，松手作为一次可撤销修改；拖动时 Esc 取消本次拖动，静止时 Esc 退出，点击框外或基本工具也退出。只读谱面不能拉伸。音效和其他按键资料保留，已有七分拍等优先保持精确分数；极小缩放导致 LN 归零时拒绝提交。

底板空白处右击新增轨道按该空白的位置插入；在主轨左边新增不会挤动主轨的屏幕位置。右击按键时仅在该按键属于多选区时删除整组选区，否则删除指针下的按键及其启用的对称对象。放置按键、创建或调整 LN 时，在画面内靠近底边不触发自动滚动；LN 明确拖出视口才允许边缘滚动。中心对称生成的同列 LN 互相交叠／相接时合成一根连续长条，异列或分离的对称对象保留。
