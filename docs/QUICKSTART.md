# SimpleManiaEditor 0.1.15 体验版

Windows x64 便携版，已包含 .NET 运行时，无需安装开发环境。

## 启动

- 双击项目根目录 `Start-Editor.cmd`，或便携包内 `SimpleManiaEditor.exe`。
- 双击 `Start-Demo.cmd`，或包内 `Demo.cmd`，直接打开生成音频的 7K 演示谱面。
- 可将 `.osu` 文件拖到应用中，或使用 `Ctrl+O` 打开。

默认新建为 **7K、原生 .osu**。从 Songs 打开时会建立包含资源的独立创作副本，编辑和保存不直接写游戏谱面库。导入音频也建立 7K 项目。工作目录可在曲库中选择；首次建议复制整个歌曲目录作为工作副本，以便体验编辑行为。复杂故事板/视频等资源的跨目录迁移尚未完善。

## 常用操作

| 操作 | 默认方式 |
| --- | --- |
| 选择工具 | `1` |
| 放单键 | `2`，左键点击空白网格 |
| 放 LN | `3`，按住左键拖动，再松开 |
| 追加/取消选择 | `Ctrl+左键` |
| 框选 | 选择工具下左键拖空白区域；Ctrl 追加 |
| 移动选区 | 选择工具左键拖动；单键/长条工具中键拖动，保持已选批次 |
| 调整 LN 尾 | 左键拖动面尾 |
| 删除 | 右键点音符，或 `Delete` |
| 缩放 | `Alt+滚轮` |
| 网格 | 顶部下拉框、调整栏刻度滑条或 `Ctrl+滚轮`；1/5、1/7、1/9、1/10、1/64 只在顶部下拉框选择 |
| 导航 | 普通滚轮向下前进时间、向上回退；方向可在设置中切换 |
| 播放/暂停 | `Space` |
| 倍速 | 顶部下拉框、调整栏刻度滑条或 `Shift+滚轮`，0.2x～2x |
| 当前时间试玩 | 顶部“试玩”，右侧选择独立试玩倍速，准备完后自动开始 |
| 复制/剪切/粘贴 | `Ctrl+C/X/V`，粘贴锚点为当前时间位置 |
| 撤销/重做 | `Ctrl+Z/Y` |
| 保存/另存 | `Ctrl+S` / `Ctrl+Shift+S` |
| 新建/打开 | `Ctrl+N/O` |
| 添加轨道 | 滚到底板空白处右键；按键轨内部不弹出 |

设置 → 快捷键折叠栏中可重新绑定；操作方案可切换到 Luma legacy，切换会重置该方案的默认快捷键。默认 osu!mania 方案的分组键移到 `Alt+数字`，避免占用 1/2/3。

播放时普通滚轮每格移动 500 ms，与网格大小无关并继续播放；暂停时每格移动一格网格。按 Space 暂停会取消待执行的旧跳转。Space 在按钮、滑条、选项上仍是播放/暂停，文本输入时保留空格。默认帧率上限为 1000，可在设置中修改。单键工具拖动保持单键；长条工具点按放单键，拖动可正向或反向绘 LN。osu 绘制工具左键命中旧键时替换重画，中键拖动移动旧键；其他工具中键拖动仍平移轨道。

左侧工具栏可以切换四个基础工具并显示当前快捷键。默认 osu style 的 LN 头、尾和单点相同，面身更窄；设置 → 快捷键中的皮肤选项可换回 malody style。Alt+滚轮缩放范围为 12～3840 DIP/beat。

快捷编辑已合并到左侧；原齿轮功能常驻上方。网格、缩放、倍速刻度在右下角卡片，拖动标题移动并记忆位置。BPM、Offset 与测定工具归入 Timing Edit。

网格默认 osu 记法：1/4 = 音乐全音符的 1/16，120 BPM 下每格 125 ms。可在设置中选 general 记法，只改变显示和输入换算，不移动音符。轨道的编辑、复制、同步和存储边界见包内 `WORKBENCH-TRACKS.md`，或仓库 `docs/WORKBENCH-TRACKS.md`。

试玩直接运行官方 osu! 游戏宿主和 mania 规则集，默认全屏，采用 lazer 的判定、计分、皮肤和 1–40 落速。7K 默认 `S D F Space J K L`，已有键位首次迁移。`Ctrl+O` 打开官方设置，`Tab` 切换自动演奏，左右 `Shift` 暂停/继续，`Esc` 直接回到编辑器，`F3/F4` 减/加落速，`Ctrl+R` 重试。右侧「设置 → 试玩」可打开官方设置、导入皮肤目录、`.osk` 和 osu!.用户.cfg。客户端会后台预热并在退出试玩后保留，热启动复用资源；独立数据目录不会覆盖已有 osu!。详细说明见包内 PLAYTEST.md。

下拉框与滑条上可直接滚轮调整，非默认选项旁显示「↶」复原按钮。「编辑器设置 → 外观」默认收起；底部横向滚动条两端各有一屏空白，可以自由安排主轨位置。OD、HP 位于「谱面」页，修改后点击「应用谱面信息」；支持撤销和 `.osu` 保存。

## 保存和恢复

原生 osu 编辑保留未编辑的 Source、Tags、谱面 ID、Editor 设置、背景/视频/break/故事板事件、未知 section 与声音属性。无改动的 UTF-8 文件可保留原文本、换行和 BOM；编辑过的音符只重写需要变化的字段。

每次覆盖保存原生 `.osu` 前，原文件备份为同目录的 `.osu.sme-backup`。若发现文件被外部修改，保存会拒绝覆盖，请另存为或重开。

应用每约 **2 秒**为有改动的文档保存恢复工作副本；另有默认 5 分钟自动备份。突然终止可能丢失最近尚未写入的短暂改动，完整 command 日志与历史版本尚待下一阶段。

用户资料独立存储：

- 设置/恢复：`%LOCALAPPDATA%\SimpleManiaEditor\Preview\`
- 默认创作目录：用户文档目录中的 `SimpleManiaEditor Maps`

应用以本地模式运行，不需要账号，不连接原作者的账号或更新服务。更新时保留用户资料目录即可。

当前完成范围与限制见 `ReleaseNotes.md`，或仓库 `docs/RELEASE-0.1.8.md` 和前版发布说明。

未完成功能以 `BACKLOG.md` 为当前清单，仓库对应 `docs/BACKLOG.md`。

0.1.6：所有轨道在同一底板；底部常驻滚动条控制左右移动，拖动表头握柄调整顺序。新增轨道不会自动跳转。默认保音高、按键高度 28 DIP；osu 放置和 LN 拖动取最近格线，按键底边代表时间，面尾需要精确点中。空白右键取消选择，底板空白滚轮也能导航。

## Timing 与整体偏移

Timing Edit 中选择「新增事件…」或「编辑所选…」（双击列表也可编辑），在弹窗中配置时间、红/绿线、BPM/SV、Kiai、事件音量和采样。取消不改谱，应用可撤销。时间提交为整数毫秒，BPM 可保留小数；参考 BPM 与音频 Offset 旁边的「应用」直接提交基础字段。原生 osu Offset 显示 beat 0 的实际歌曲时间，保留导入原文件的未编辑精度。

允许在 Offset 之前放置按键。调整整体偏移时，选好网格和选择工具，Ctrl+A 后拖第一颗音符到目标格线。设置 → 编辑器设置里的「全部吸附」默认开启；已写入的更细分度仍保留，换网格不重写谱面。撤销/重做到历史末端按钮变灰。

音量位于设置 → 音量与音频。显示和字体缩放位于设置 → 编辑器设置 → 外观。
