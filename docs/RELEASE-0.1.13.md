# 0.1.13：进入试玩时切换窗口焦点

- 点击「试玩」后，等待自有游戏窗口真正显示，再从编辑器把 Windows 前台和键盘焦点交给游戏。修复仅请求 SDL 显示/置顶、窗口弹出后编辑器仍持有焦点的问题。
- 首次进入、退出后重复进入、最小化窗口恢复使用同一交接流程；不修改游戏全屏和皮肤设置。
- 焦点交接限于当前编辑器启动的子进程，最多等待 10 秒；退出或启动失败会取消。如果等待期间主动切换到其他应用，不继续抢焦点。
- 自动回归使用真实 Windows 编辑器测试窗口和官方 GPU 游戏宿主，逐次验证前台进程属于游戏，同时保留常驻进程、编辑副本、异常重启与关闭验证。

关闭旧编辑器窗口后运行根目录 `Start-Editor.cmd`，或便携目录中的 `SimpleManiaEditor.exe`。
