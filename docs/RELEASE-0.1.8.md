# 0.1.8 osu! stable 兼容试玩

用户选定传统 stable 作为默认手感目标。默认试玩方案改为「osu! stable 兼容」，旧版四档自定义判定保留，切换方案会重置当前试玩。

- 判定为 MAX / 300 / 200 / 100 / 50 / MISS，读取谱面 OD，采用官方 Classic 原生 mania 窗口及半毫秒舍入。倍率补偿保持实际毫秒窗口基本一致；晚侧超过 100 窗口直接 MISS，没有晚 50。
- LN 按 stable ScoreV1 文档合并头尾误差、一次计入准确率；头部 MAX/300 容错分别为 1.2/1.1 倍。中途松手可重新按住，最终最高 50；错过松手窗口会 MISS，不再到面尾自动判满。
- MAX 和 300 准确率同为 100%，200/100/50 权重为 2/3、1/3、1/6。提供无 Mods 的一百万制 base/bonus 分数；整图完美为一百万，中途试玩按本次对象归一化。
- 滚动按毫秒连续积分 BPM/SV，以按时长最常见 BPM 归一化；不再每帧将音频时间量化到 beat 网格。倍率调整补偿画面滚动距离。
- 按键底边代表时间；7K 使用对称的内置列配色。LN 头在自身时间后才停在判定线，按住时保留面头，面尾使用清楚的按键图形。添加即时列亮、判定字与误差条。
- 帧直接读取当前音频时钟，避免读取后台旧样本；头、尾、自动超时使用相同手动偏移时钟。偏移单位为实际毫秒，正数将输入时间前移，视觉和 AutoPlay 使用原音频时钟。
- 试玩设置显示实际 OD/倍率对应的窗口。stable 方案禁用旧自定义窗口滑条，避免界面参数与判定不一致。7K 空格键、键盘重复、焦点按钮和松手路径已回归。

来源固定为 ppy/osu `7e25f111466f1b5648d86856e5737d852402effe`，公式进行轻量移植；仓库保留参考源码，包内带 MIT 许可。不是嵌入完整 osu! 客户端。来源与适配见 `third_party/osu/UPSTREAM.md`。

边界：没有复刻 HP/失败、Mods、回放、排名上传或 stable 的完整 combo/tick 行为；没有实现 osu skin 导入和完整谱面 hitsound 样本库。当前 hitsound 仍是编辑器已有的手动音效输出。流速控件仍以 px/s 表示，不能直接照填 stable 的 1–40 数值。设备、显示器和熟悉皮肤的真实手感需 mapper 验收，自动回归不证明硬件延迟相同。

验证：50 项核心回归、真实 Avalonia 输入/设置/截图、100k 按键可见区裁剪，以及发布包解压启动检查。
