# 0.1.18：导入网格、输入焦点与播放性能

- osu 操作模式打开新 `.osu` 默认启用网格校准，修复旧默认直接绕过校准的路径。覆盖 1/1～1/64 的全部预设，包括 1/5、1/7、1/9、1/10；LN 两端分别校准，极短 LN 不塌成单键。误差窗口仍为 2 ms 且 1/192 拍，超出窗口的刻意偏移保留。BPM 锚点和保留毫秒模式使用百万分之一拍精度。保留原始 `.osu` 时间戳，未编辑直接保存仍逐字保真。
- 设置 → 编辑器设置新增「吸附选中」「吸附全部」，作用于当前主轨或草稿轨。旧工作区缓存不会被静默量化；需要修正时可明确执行这些命令。当前网格会吸附单键和 LN 两端，短 LN 至少保留一格，负拍支持，保护与只读检查生效，一次撤销即可恢复。不会自动合并重叠按键；交由现有检查提示。
- 从文本输入框点击轨道底板或其他空白位置会释放焦点，不丢弃输入内容；点击输入框、选项或按钮保持正常交互，Space 随后可用于播放/暂停。
- 默认优先直接 OpenGL，驱动不支持时退回 ANGLE/软件；通过桌面合成呈现，不启用先前出现撕裂的低延迟 DXGI 交换链。设置 → 编辑器设置 → 外观可选择兼容 ANGLE/WinUI 或软件渲染，保存后重启生效；异常驱动也可在启动前设置 `SIMPLEMANIA_RENDERER=angle` 或 `software`。
- 高采样播放与界面更新分离：1000/2000 Hz 音频时钟采样不再等待上一帧合成回调。界面最多 240 次更新/秒，只保留一个待处理更新，播放结束、试玩、关闭时停止。仅播放时请求 Windows 1 ms 等待精度，退出采样线程时配对释放。新增 180 和 2000 档；这些上限不保证同等画面 FPS。
- 缓存歌曲结束范围、时间轴刻度文字和全局难度按屏幕行聚合的数据；同步对照轨的时间投影提高精度，减少高缩放下的步进。状态栏分别显示绘制 FPS、慢帧参考和时钟采样。绘制计数是 `TimelineSurface.Render` 调用，非显示器实际 Present 次数；「1% low≈」为 `1000 / P99 帧间隔`，不等于最慢 1% 帧的平均帧率。

验证：53/53 核心规格及完整 UI、皮肤、DSP、轨道、试玩互斥回归通过。新增测试覆盖默认导入校准及原始时间戳保留、奇数/细分网格、负拍/LN 批量吸附、保护、撤销和空白焦点。

真实 Windows/WGL 窗口单次 6 秒采样：1440×960 窗口、180 Hz 屏幕、无音乐编辑时钟，4000 键约 144 绘制 FPS，50000 键约 110。旧版 50000 键样本约 44；两次预热时长不同，属于方向性对照。**尚未达到稳定 180，更未达到 1% low 180。** 实际音频设备、全屏大窗口、频谱和多个轨道须继续验收。细节见 [性能记录](performance/EDITOR-RENDER-0.1.18.md)。官方游戏宿主未修改玩法，本轮不重跑其 GPU 判定验收。
