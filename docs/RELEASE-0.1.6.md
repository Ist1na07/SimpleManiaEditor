# 0.1.6 交互修正

- 在按键轨空白处右键取消按键/Timing 选择；在底板空白处右键也取消各轨选择并打开添加轨道菜单。
- osu 方案中按键底边始终表示其实际时间。放置按键直接将鼠标时间吸附到最近格线，与按键厚度无关；半格取后一个时间点。
- LN 新建及面尾调整同样使用鼠标最近格线；精确面尾调整入口在面尾实际时间点。malody 方案保留原有显示锚点选项。
- 底板空白区域支持时间滚轮、Ctrl 网格、Shift 倍速及 Alt 缩放，复用现有导航和播放跳转。
- 底板下方横向滚动条设为常驻 24 DIP，关闭自动隐藏并加粗拖动柄；控制整个底板左右平移。

新增回归覆盖不同厚度的放置/底边锚点、细网格 LN 面尾双向拖动、空白取消选择、底板滚轮和滚动条可见性/控制。音频及 osu 本体实机验收仍由 mapper 进行。

本轮尝试连接 ZCode Desktop，但窗口捕获两次超时，未提交外部模型任务；代码与验证由本地开发流程完成。
