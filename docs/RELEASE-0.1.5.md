# 0.1.5：统一底板、精确放置与 Songs 隔离

- 从 Songs 打开的谱面自动复制选中 mapset 到独立创作目录的 `Imports/`，包含音频、图片、故事板和子目录资源。再次打开复用已编辑副本，不覆盖它；默认保存、新建和旧缓存保存也避开 Songs。另存到 Songs 被阻止，明确导出仍是单独操作。
- 用户未保留此前 osu 警告原文，本版修复已确认的直接写入风险；不宣称已复现并修复某个特定 osu 修复程序报错。
- 编辑器默认变速保音高，升级旧默认设置时启用；仍保留明确开关。默认按键高度从 41 降到 32 DIP，自定义高度保留。
- osu 放键按鼠标时间取前一条网格线，和按键厚度无关。LN 尾调整范围收窄到尾部中心约 3～6 DIP，横向不再额外扩大。
- 主轨、草稿、对照、hitsound、density/diff、波形/频谱和指标轨共用底板容器；主轨与附加按键轨复用 TimelineSurface。底部滚动条控制整个底板，拖动表头左侧握柄调整顺序并保存。
- 新增轨仅追加，不改变主轨宽度或自动跳到最右；切换工具和获得焦点也不自动拖动底板。
- 波形/频谱成为与 density/diff 同宽的独立紧凑栏；不再限制在主轨内部。侧边可视化缩放统一到 12～3840，移除旧 480 上限。
- 同步对照轨使用歌曲时间到主轨时间轴的投影；不同 BPM/高缩放下，同一歌曲时间的绘制位置一致，光标红线对齐。
- 顶部命令和倍速/网格选项合成同一固定栏。修复旧网格跨度残留，以及快捷编辑内容固定 84 宽导致的图标/边框溢出。
- 仅底板空白处右键显示添加菜单；按键轨内部空白不显示。菜单显示后第一次在底板内左键只关闭菜单，不放键。

## 验证范围

自动测试包含：Songs 文件集合/字节不变、嵌套资源复制、编辑副本保存及复用、安全新建；厚度 8/32/100 下点击落到前线、精确面尾；单一顶部栏、底板菜单及关闭点击、不跳宽度或偏移、实际拖动波形栏与顺序落盘；不同 BPM 在 1920 缩放下同时间点像素位置一致，波形保留高缩放；原有原生 osu 保真、恢复、复制、撤销和试玩等回归。

核心 49 项规格和界面/轨道回归通过，构建零警告、零错误。仍需 mapper 验收真实 osu 提示、设备音质/延迟和真实歌曲。
