# 0.1.27 慢放时间对齐、频谱与界面

- 对照官方lazer/framework并用用户Albemuth MP3复现：原PCM约208ms首声，被旧100ms粒度伸缩映射至0.1x的119ms。更短粒度、原PCM静音区保护及慢速搜索前置补偿已修复这个起音／跳转案例，没有移动频谱或改写谱面offset。
- 补入非谐波音色、不同声道、多段延迟短音、歌曲首尾及读块测试。极低速时间伸缩仍可能改变连续音乐内部瞬态与音色；本版降低长片段重复与起音误差，不承诺任意音乐的无损10倍慢放。
- 频谱改为合并各声道功率，反相内容不再被mono平均抵消。
- 底部时间轴始终显示整首音频；空谱导入音乐后自动更新，超出音频的物件不会拉长歌曲时间轴。
- 操作／外观分类直接展示内容，移除冗余折叠控件、重复标题和外框。

关闭旧编辑器后运行根目录Start-Editor.cmd。用户源音频、旧便携目录与谱面文件不被手工修改。
