# SimpleManiaEditor 0.1.38

本轮处理三件来自实际使用的问题，并补上两项功能：曲库要"一进去就是好的"、非 1x 播放的卡顿与爆音、标签页溢出点不到；新增只读谱面顶栏「编辑」和 osu 风格搜索。

- **曲库进入与索引**：进入曲库/启动只读持久化缓存快照，不再隐式扫描；唯一全量扫描入口是「刷新索引」按钮，文件监听只提示不自动扫。索引改为 osu 模型：导入时解析一次，Title/Artist/Creator/Version/KeyCount/Format/Source/BPM/Length 全量落库，刷新只处理新增或 mtime/size 变化的文件，删除项同步移除。旧索引原地升级并后台回填，回填期间可正常搜索。合成 2 万张：首次导入约 10.4 秒（后台分批）、二次进入 216 ms、无变化刷新 288 ms、改 1% 文件刷新 443 ms（全量解析需 10.1 秒，约 22.7 倍）。
- **搜索**：支持 osu 语法 `mapper=`、`key=`、`artist=`、`title=`、`diff=`、`bpm>=`、`length<`、`source=`、`tag=`，运算符 `=`/`:`/`!=`/`<`/`<=`/`>`/`>=`、引号短语、`-排除`；未知字段回退为文本搜索。2 万条查询 2.6–4.1 ms（旧路径 34–42 ms），逐谱面匹配零分配。「★ 收藏」「未发布」两个快捷筛选现在对左右两栏都生效。
- **非 1x 音频**：改为预取管线——专用生产者线程 + 1.4 秒环形缓冲，音频回调只做拷贝；去掉每段结尾的 64 ms 历史回灌与补零（"每个音符响两次"的根因）。实测：回调 p99 从 15.75 ms 降到 0.012–0.28 ms、零欠载；24 个 click 出声 24 次（原 48 次，0.1x 为 96 次）；起音峰值 0.58→0.73（源 0.79）；8 秒稳态和弦从 66 段误切降到 1 段；50 ms burst 内部静音空隙 10.85 ms→0。1x 仍走直通，不做预取。
- **只读谱面「编辑」**：只读曲库谱面打开后，谱面上方工具栏最左出现「编辑」，一键把整套谱面克隆到工作区并以可编辑标签打开；克隆期间按钮禁用，双击不会产生第二份，源文件逐字节不变，失败保留原文件。
- **标签页溢出**：标签条仅在溢出时支持滚轮横滚与 ‹ › 翻页，激活标签自动入视；未溢出零占位。

**已知限制**：`length` 是 osu 口径的可玩时长（最后音符 END − 首音符 START），不是音频时长；star 评分、ar/od/hp/dr 等字段索引中没有数据，按未知字段回退文本。真实 4.6 万张用户库的迁移与回填、真实耳机/声卡的听感、真机标签条手感仍未验收；本轮音频结论来自设备前 PCM 与回调计时。`--mapper-033` 存在既有间歇超时，根因未定位。

**分发**：两个 Windows x64 包，完整解压后双击根目录 `SimpleManiaEditor.exe`，不需要安装 .NET。
- `Full`：编辑器 + 官方 osu!mania 试玩宿主（含 osu!lazer 运行时），**不需要另外安装 osu!**。首次启动试玩预热会在包内 `osu-host\cache` 生成约 100 MB 字体/着色器缓存（纯缓存，可删可重建），因此请解压到可写目录，不要放在 Program Files。
- `Portable`：仅编辑器，体积更小，试玩不可用。

两个包都不含个人谱面、音乐、皮肤、设置、曲库索引或 Git 历史。程序未做代码签名，Windows SmartScreen 或杀软可能提示，需选择"仍要运行"。
