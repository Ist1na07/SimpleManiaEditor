# 0.1.4：固定工作台与独立轨道

- Shift+滚轮按预设调整倍速；Ctrl 网格、Alt 缩放继续有效。
- 统一 osu/general 网格显示和输入换算：osu 1/4 = general 1/16，120 BPM 下为 125 ms；切换样式不移动已有音符。
- 上方倍速和网格恢复下拉框。“调整”改为网格、缩放、倍速横向滑条，带可点击刻度，默认展开。
- 齿轮功能常驻上方；快捷编辑全部合并到左侧固定工具栏。旧版默认收起的面板在首次升级时展开。
- BPM、Offset 和测定工具移到 Timing Edit；谱面与 Timing 分别应用，保留另一分类的未提交输入。
- 右键空白添加草稿、只读对照、hitsound、密度、实验性局部负荷轨。支持隐藏/恢复显示、同步开关、草稿编辑与撤销、跨轨道排列复制、明确放入主轨。
- 轨道用独立明文清单和 `.mc` 快照保存，不进入 `.osu`；约两秒自动保存、正常保存/关闭等待落盘、保留上一份文件、损坏时拒绝覆盖，另存为复制工作区。

轨道操作、存储路径和当前边界见 [工作台与轨道说明](WORKBENCH-TRACKS.md)，剩余功能见 [BACKLOG](BACKLOG.md)。局部负荷轨是实验性分布指标；官方 strain、Sunny 7K、完整 hitsound 继承和独立音频轨尚未完成。
