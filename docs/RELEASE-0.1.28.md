# 0.1.28 · 小屏界面、曲库与 osu 文件隔离

界面默认基于当前屏幕有效分辨率：1920×1080约75%，2560×1440为100%；55%–200%手动调整，字体可独立调整。自动模式跨屏更新，手动比例持久化。旧100%默认设置迁移到自动模式，其他已有手动比例保留。外观分类最上方提供入口。正常启动窗口使用更宽的工作区，受当前屏幕工作范围约束。主轨、音频和一个草稿轨在1080p/1440p布局测试中可同时显示。

曲库入口是左上角品牌；曲目卡片可滚动、展开难度，搜索曲名/艺人/作者/难度/路径，可筛选创作目录与只读来源。添加/移除只读曲库不改变保存目录或源文件。默认创作位置为包体旁Maps，包内app子目录正确回溯到启动入口所在目录，已有自选创作位置保留。上一版分发包自动创建的本机Maps保留为曲库链接，默认改到包旁；不会搬动或删除原文件。

修复首页只扫描一个目录而遗漏打开/历史创作文件：持久化记录已收录谱面，扫描时结合创作目录、只读库和记录；新建/导入/保存只增量更新受影响曲目，后台扫描同时发生的新编辑不会被旧索引覆盖。读取元数据头部并按文件大小/修改时间缓存，列表保留虚拟化。扫描/导入只读文件允许其他程序写入和替换，避免扫描时锁住官方编辑器的保存。50k/200k真实曲库仍需专门基准。

外部单文件导入只复制该谱面及其引用资源，不递归复制桌面/临时目录。Songs/mapset导入保留资源目录；编辑后重开同一来源不覆盖已有创作副本。谱面与音乐仍是普通本地文件。来源不可用时显示路径提示，其余曲库仍可使用。

文件审查发现保存以外的保护缺口：导出与库删除原先可指向Songs，路径检查也没有覆盖目录链接或改名的Songs。现统一检查osu安装标志及真实路径，保护保存、另存、导出、删除、资源写入、编辑缓存和官方试玩数据路径。试玩仍使用编辑器专属配置/数据库，读取osu配置与皮肤。导出到独立目录后请使用osu自身导入。

验证：59项核心测试、完整无界面UI/播放回归；新增六曲创建、搜索/来源、资源导入、保存后索引更新、重开、1080p/1440p布局与标题入口测试；模拟安装中的谱面/配置/数据库的SHA256及修改时间在所有操作后不变，Windows junction不能绕过保护。使用临时数据，未运行或修复用户osu安装。

尚未复现用户具体的osu修复提示，不能断言该提示的所有原因已消除；本次修复了审查确认的写入路径。设备音质、物理音画校准和稳定180fps仍需实机验收，未被本轮布局/存储测试替代。
