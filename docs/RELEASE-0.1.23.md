# SimpleManiaEditor 0.1.23

- 修复旧缓存导出 Offset 归零。Lament 缓存已有475ms，但保留的原始 Timing 行仍是0；现在导出会识别这类过期基准并生成正确时间行，无需重建谱面。单谱 .osu 与谱包 .osz 都覆盖。
- F5 默认从当前播放位置进入官方试玩，可在“设置 → 操作 → 快捷键”自定义；启动流程与试玩按钮相同。
- 启用中心对称后，右键、Delete、擦除同步删除范围内具有相同头尾位置的对称按键，一次撤销恢复。剪切会复制并删除整对；涉及锁定范围时拒绝整次删除。
- 默认 osu 操作方案中，按键底边与格线上边缘对齐。实际时间、最近网格放置与 LN 松手吸附逻辑保持原意。
- 设置面板改为固定搜索框和七类导航：编辑、操作、外观、音频、试玩、存储、通用。统一字号、间距，清理重复的当前网格入口和快捷键标题；“固定分度”改名“快捷键目标网格”。搜索显示匹配类别并临时展开折叠项，清空后恢复，各分类保留本次会话滚动位置。

验证：57项核心规格及完整界面回归通过；含旧缓存保存/重新导入/单谱和谱包导出、对称Tap/LN删除与撤销、右键真实指针、格线上边缘对齐、F5实际窗口路由、分类搜索及折叠恢复。用实际Lament工作缓存只读导出，官方osu解析器确认两个导出均为475ms、104.04 BPM、190个按键，原谱面与工作缓存校验值不变。便携包执行启动和7K/LN读写检查。宿主游戏代码本轮未改。

旧导出文件不会自动改写，请在新版重新导出再导入osu!。
