# SimpleManiaEditor 0.1.21

- 播放红线在音符下层绘制，不再遮住单键与 LN。
- 中心对称框的上下时间边仅在选择工具下可拖动；单键、长条工具在这些边缘正常放置。左右列边仍可调整。
- 绘制覆盖按吸附后的格线命中音符头；从音符实际位置下方起拖也能替换成 LN。右键删除和中键移动仍按可见音符命中。
- 暂时隐藏分组页、分组属性、入口、快捷键及标识；旧文档分组数据继续保留。
- Ctrl+H 左右镜像，Ctrl+G 上下翻转。上下翻转按选区最早头、最晚尾的时间中心反射，LN 交换头尾后保持正向；一次撤销恢复。支持草稿轨。
- Ctrl+B 在当前位置添加跳转标记；全局密度的标记与底部时间轴书签可右键删除。全局密度/难度统一标题高度和时间范围，书签不再导致播放线不同步。
- 除网格外，滑块拖动连续变化，点击轨道/刻度选择离散值；缩放和倍速按相邻预设插值。
- 音符拓展工具入口移到左侧。全局密度/难度的显示开关只保留在顶部“显示 / 布局”，隐藏后可在这里恢复。
- 默认 osu 最小模式，隐藏 hitsound 编辑、音效轨与 SV 编辑；设置 → 编辑模式可切换 osu 完整模式，选择会保存。隐藏不删除原谱面的事件或音效，导出和试玩继续使用原数据。
- 导出仅提供 osu!mania，OD/HP 直接使用谱面属性，删除重复填写的导出控件。旧格式的内部解析与恢复缓存继续保留。

验证：56 项核心规格；完整 UI 回归覆盖真实指针覆盖绘制、框边操作、滑块拖动/点击、Ctrl+H/G/B、模式隐藏与恢复、书签删除、导出 OD/HP，以及现有轨道、音频、皮肤和保存恢复流程。便携包另做启动与读写检查。

本轮没有改动官方游玩宿主逻辑。画面性能的真实设备验收仍按 0.1.18 的已知限制记录。
