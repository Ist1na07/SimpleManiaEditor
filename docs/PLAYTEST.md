# 试玩

在编辑器顶部点击试玩，从当前时间进入。默认全屏；窗口方式可在设置中保存。旧设置中的 AutoPlay 选择会保留，手动体验时在 F1 设置中关闭 AutoPlay。

| 操作 | 默认按键 |
| --- | --- |
| 7K 演奏 | S D F Space J K L |
| 开始/暂停 | Enter；未绑定到轨道的 Space |
| 暂停菜单/继续 | Esc |
| 展开/收起设置 | F1 |
| 全屏/窗口 | F11 |
| 落速加/减 | F3/F4 或 Ctrl/Shift + 加/减号 |
| 重试本次起点 | Ctrl+R；可导入 osu 自定义重试键 |
| 返回编辑器 | 暂停菜单「返回编辑器」或窗口上方「关闭」 |

设置是浮层，不改变轨道大小。展开设置会暂停。演奏键位优先于升降速等全局键，Esc 保留为暂停键。取消键位捕获也用 Esc。设置和皮肤路径保存在应用本地 `playtest-settings.json`。

## 导入自己的设定

按 F1，进入「按键」，点击「导入 osu!.用户.cfg 键位与落速」，在 osu 安装目录选择 `osu!.你的 Windows 用户名.cfg`。导入每种 K 数的普通布局、落速、当前皮肤路径和部分试玩全局键。不会导入账号、密码、聊天或游戏库资料，也不会写回 osu 配置。

如果皮肤采用较老的 `Key0:` 到 `Key6:` 设定，可在选好皮肤后点击「导入当前皮肤的旧 Key0… 键位」。选择皮肤本身不会擅自替换键位。Co-op 的 `ManiaLayouts#KSplit` 不导入到普通单人布局。

## 皮肤

按 F1，进入「皮肤」。点击「添加皮肤目录 / osu! Skins 目录」添加一个皮肤或整个皮肤库，或点击「导入 .osk 皮肤包」。随后在上方列表切换；中间显示当前 K 数的预览。内置皮肤也从同一个列表选择。修改过图片后点击「重新加载当前皮肤」。Note 外观调整已移除，皮肤负责尺寸、颜色、位置和素材。

皮肤库保存在本应用数据目录的 `skins/library.json`，选中项保存在 `playtest-settings.json`。导入包解到 `skins/import-…`，不修改 osu 的 Skins 目录。目录失效后保留已保存的选择并报错；首次加载失败使用内置图形，已有皮肤继续显示。目录恢复后可重新加载。选择立即保存，加载中退出不会丢失选择；声音损坏只回退音效，不拒绝图像。

当前游戏素材支持：

- 单点、LN 头/身/尾、未按/按下的键；自定义 `NoteImage#…` / `KeyImage#…`；缺尾回退为头，缺 LN 头回退为单点。
- 舞台边框、底板、判定线、列光、命中/长条光；列光颜色及命中光加法混合。
- 六档判定图片、连击数字、分数/准确率数字与前缀/重叠、百连击 burst、暂停继续/重试/返回素材。
- 多个 K 数 section、可变列宽/间距/线宽、位置、面身拉伸和平铺、层级、上滚、翻转、分舞台间距、特殊列。
- PNG/JPEG、高清图、以 `-0` 开始且连续的动画帧；mania 音符与判定按固定 60 FPS，舞台光采用配置帧率，部分其他动画采用 General.AnimationFramerate。
- 皮肤的 normal-hitnormal 按键声音，预解码后混入现有音频输出。此项不等同于完整谱面 hitsound 采样继承。

无对应 K 数 section 使用默认布局和可用图像；不完整皮肤逐项回退。非游戏部分（选歌、菜单光标、在线 HUD 等）不载入。HP、失败与相关 scorebar/ranking 素材尚未接入。皮肤版本、特殊面身重复模式、双舞台独立判定/连击、组合 burst 的精确历史表现还需逐皮肤验收，当前不能保证所有第三方 skin 像素级一致。图片损坏/过大时跳过并显示提示，不让皮肤错误中断谱面编辑。

## 落速和判定

默认方案采用 lazer 的 1–40 落速单位：官方时间范围 `11485 / speed` ms。20 对应 574.25 ms，26 对应约 441.73 ms。这个范围以默认判定线标定；调整皮肤判定线会改变可见提前量，但不改变相同音符间的像素距离。不同显示高度保持相同比例的落速，倍速播放继续做速度补偿。

判定默认仍是上一版 stable ScoreV1 兼容：OD 六档窗口、LN 联合头尾、无 Mods 分数。界面/落速改为 lazer 风格不代表已换成 lazer 的完整计分引擎。可选旧版自定义四档与 px/s。当前没有 HP/失败、Mods 或排名提交。后台时钟与真实音频输出沿用现有引擎；自动测试不能证明和用户设备上的 osu 有相同端到端延迟。
