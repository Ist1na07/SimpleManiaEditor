# SimpleManiaEditor 0.1.26

关闭旧窗口后双击根目录 `Start-Editor.cmd`，或使用 `dist/SimpleManiaEditor-0.1.26/Start-Editor.cmd`。试玩继续使用官方 lazer 游戏界面，当前修改针对编辑器播放。

## 倍速音质与延迟

- 编辑器所有保音高倍率统一采用单阶段 SoundTouch，左右声道共同处理。移除0.1x/0.25x的串联变调链；已知双声道和弦测试中的额外频谱成分明显降低。
- 所有倍率提前准备首段音频并完整保留，避免开始播放后才做启动处理，以及因丢弃预热样本改变歌曲起点。
- 播放中跳转和改变倍速在独立音频链上准备，再切换到现有输出设备；准备期间旧播放继续，过时请求取消后保留旧流。避免直接修改正在被读取的变速处理器。

## 播放性能与界面

- 多轨播放采用轻量位置同步，布局、皮肤、网格或缩放改变时才完整同步；仍以歌曲毫秒对齐不同BPM/offset的轨道。
- 独立轨道取消同步后恢复暂停轨道的滚轮逻辑。
- 音频设置新增可见的播放状态和“重建音频输出”入口。
- 自定义倍速选项在展开时保持稳定，不再因后台刷新反复重建列表。

## 验证

59项核心规格和完整界面回归通过。实际DSP覆盖10种倍率、单/双声道、复杂扫频/打击、相同声道与单侧静音、开头脉冲、时长/EOF及不同读块一致性；多倍率跳转取消与输出设备复用通过。另测48k双声道WAV/MP3/Ogg，每种格式、每种倍率8次跳转及持续播放。

详见[音频与同步基准](performance/AUDIO-PLAYBACK-0.1.26.md)。这些结果不代表真实声卡和屏幕的端到端延迟；真实歌曲慢放的音质、连续滚动听感与稳定180fps仍待实机验收。
