# 0.1.19：中心对车辅助工具

左侧固定工具栏新增「中心对车」，点击设置时间起止与参与列。默认关闭，F6 切换；快捷键可在设置中修改，迁移时若 F6 已有自定义绑定会保留旧绑定。

- 时间与参与列同时反向映射。7K 全列时 1↔7、2↔6、3↔5、4↔4；范围 8～16 拍内，9 拍的第 1 列对应 15 拍的第 7 列。局部列按所选列的空间顺序两端对应，时间范围可从当前视口或选区取得。
- 单键和 LN 放置同步生成对称按键，反向拉 LN 保持面头/面尾顺序；悬停/绘制时显示对称预览，范围和中心线淡色标记。仅范围内完整对象参与，跨越范围的 LN 保持整条。中心自身对称的对象只创建一次。
- 普通放置、原键替换与对称伴随键一起提交为一次操作，撤销/重做一次处理整组。对称位置已有同样布局时跳过重复；有不同对象或锁定范围时阻止整次放置，保留原对象。仍由现有检查报告 LN 接触和重叠等问题。
- 「补齐选中按键」按填写范围生成已有选区的对应对象，一次撤销；音量、采样和分组随对象保留。目标位置索引一次，避免为选区中的每个对象重新扫描整图。
- 主谱与各草稿轨的工具设置分别保存到应用数据目录 `drawing-tools/*.json`，明文并原子写入，不进入 `.osu`；下次打开恢复范围和启用状态。引用轨只读。工具状态用弱引用关联会话，关闭谱面不会因此保留整个文档。

生成后的按键可独立移动、调整面尾和擦除；本轮提供放置辅助及选区补齐，关联编辑、更多对称/排列工具继续列在清单中。0.1.18 的网格、输入焦点和播放改进保留；稳定 180 / 1% low 180 的性能目标仍未完成。

验证：54/54 核心规格；完整 UI 回归及最终工作台回归通过。覆盖 7K 单键/反向 LN 指针成对放置、一次撤销、旧对象替换冲突无部分修改、局部列、有理数、负拍、等价分数去重、锁定、F6 迁移/切换、设置恢复和主/草稿设置隔离。便携包检查通过；官方游戏宿主玩法未改动。
