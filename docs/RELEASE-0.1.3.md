# 0.1.3：osu 交互与编辑工作台

日期：2026-10-08。

- 编辑区空格固定为播放/暂停，按钮、网格/速度滑条、非文本选项获得焦点也不会改为激活控件。文字输入保留空格，快捷键捕获仍按设置流程工作。
- 固定顶部工具栏和展开的齿轮菜单各占布局行；其他浮层位于谱面区域，不再遮盖顶部控件或工具栏。
- 播放中普通滚轮每格按 500 ms 定位，与网格、BPM 和缩放无关；暂停时保留一格网格定位。方向设置继续有效。
- 缩放从 24～480 扩大到 12～3840 DIP/beat；设置和重启保存采用同一范围。
- 默认 osu style：单点、LN 面头、面尾采用相同外观，面身宽度为端点宽度的约 76%；保持原配色。原外观命名为 malody style，在设置 → 快捷键/操作方案区域选择并保存。
- 左侧固定选择、单键、长条、擦除工具栏，显示当前快捷键；按钮仅切换工具，擦除按钮不额外删除已有选区。
- 顶部右侧网格改为滑条，可手动选择全部 16 个预设。Ctrl+滚轮循环列表为 1/1、1/2、1/3、1/4、1/6、1/8、1/12、1/16、1/24、1/32、1/48、1/64；1/5、1/7、1/9、1/10 仅手动选择。
- 顶部速度滑条支持 0.2x～2x，拖动显示候选速度，释放时应用，避免逐像素重建 DSP；继承现有保音高设置。
- 顶部“试玩”以当前时间、当前速度/保音高设置进入试玩，音频准备好后自动开始，无需再按开始。
- 新增 [当前未完成清单](BACKLOG.md)，按原需求列出部分实现、待补齐和原 TODO 扩展。

## 验证范围

新增回归覆盖不同网格下的播放中固定时间跳转、暂停网格导航、扩大缩放、皮肤偏好持久化、顶部菜单不重叠、滑条/滚轮同步、按钮/滑条焦点下的 Space、1x 以上速度和当前位置自动试玩。音频测试消费真实解码/DSP 输出，但使用模拟设备；实际音频设备和 osu! 环境由用户体验确认。
