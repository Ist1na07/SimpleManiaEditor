# 工作台、网格与轨道

## 网格记法

内部时间坐标以一拍（四分音符）为单位。osu 的分母是每拍的切分数；general 的分母是全音符的切分数。网格样式可在设置 → 快捷键/操作方案区域选择，与按键方案、音符皮肤分别保存。

| osu style | malody / general style | 120 BPM 时每格 |
| --- | --- | --- |
| 1/1 | 1/4 | 500 ms |
| 1/2 | 1/8 | 250 ms |
| 1/4 | 1/16 | 125 ms |
| 1/8 | 1/32 | 62.5 ms |
| 1/16 | 1/64 | 31.25 ms |

切换记法不移动音符、不改变实际网格间隔。原预设按 osu 记法保存，general 显示分母乘四；自定义 general 分母须为四的倍数。osu 分母最大 1920，对应 general 最大 7680。

定义参考 [osu beat snap divisor](https://osu.ppy.sh/wiki/en/Client/Beatmap_editor/Beat_snap_divisor)；实际间隔由本项目 TimingMap 和交互回归校验。

Ctrl+滚轮调整常用网格，跳过 osu 1/5、1/7、1/9、1/10、1/64。Shift+滚轮按倍速预设调整；Alt+滚轮缩放。播放中的普通滚轮保持每格 500 ms，暂停时按当前网格移动。

0.1.6 起，osu 按键放置和 LN 拖动以鼠标最近格线吸附，底边代表按键实际时间，吸附不受按键厚度影响。轨内空白右键取消选择；底板空白也支持滚轮导航和上述修饰键。横向滚动条常驻底板下方，内容超出可视宽度时显示拖动柄。

0.1.22：LN 新建和面尾调整拖动时连续预览，松手才吸附；不改音符显示锚点。工作台按谱面恢复自定义轨道、排序、底板平移及视口。

0.1.7 起，单键工具只能放单键，长条工具点击放单键、拖动生成 LN。osu 绘制工具左键命中旧键则替换重画，中键移动旧键；整个 LN 面尾按键区域都用于调整长度。鼠标预览的底边中心对应鼠标尖部，实际提交仍取最近格线。

## 固定工作台

原齿轮中的文件、保存/恢复、播放、检查、导出、分析及拓展等命令常驻上方。上方倍速/网格使用下拉框；调整栏中的网格、缩放、倍速是横向滑条，刻度标签可点击直接选值。

快捷编辑合并到左侧固定工具栏，保留原动作和快捷键提示。网格/缩放/倍速位于右下角可拖动卡片。网格、倍速、缩放和底板平移不提供恢复按钮；全局外观、快捷键等偏好保留。

右侧“谱面”管理标题、艺术家、制作者、键数、资源和难度设置。“Timing Edit”管理参考 BPM、音频 Offset、BPM/Offset 测定以及 Timing/SV 点。两类应用按钮不会顺带提交另一类未完成的输入；保存会检查全部待提交表单。

## 添加与使用轨道

在底板空白处右键打开添加菜单，按键轨内部不弹出。主轨与附加局部轨道位于同一底板；底部滚动条移动整个底板，拖动表头左侧握柄调整顺序。新增只追加轨道，不改主轨宽度或跳滚动位置。菜单打开后的第一次底板内左键只关闭菜单。

主轨始终保留；附加轨可隐藏、恢复显示和切换同步。全局密度/难度固定在左侧，可隐藏并从顶部“显示 / 布局”中恢复。局部密度/难度、波形/频谱是可拖动的独立紧凑栏。主轨和附加按键轨使用相同组件与尺寸配置。

| 轨道 | 当前行为 |
| --- | --- |
| 草稿按键 | 独立按键/LN、选择、移动、删除、撤销重做；编辑资料和主谱隔离 |
| 其他谱面对照 | 导入 `.osu` / `.mc` 的只读快照，按歌曲毫秒同步，支持关闭同步独立浏览；不改原文件 |
| hitsound | 选择主谱音符后显示当前自定义采样与音量，应用为可撤销的主谱修改；空采样表示清除自定义文件 |
| 局部密度 | 主谱正式键头的 500 ms 滑动窗口数量换算为每秒，草稿不计入；后台采样、可见区间连续绘制 |
| 局部难度（实验） | 滑动窗口密度加同列短间隔及 LN 权重，用于初步看分布；不是官方星级，也不是 Sunny 7K |

同步轨按歌曲毫秒投影到主轨时间轴；不同 BPM 时同一歌曲时间的像素位置一致，红线对齐。波形/频谱也使用相同缩放范围。关闭同步后保留自己的视口，滚轮不移动主轨。

点击草稿或对照轨后，键盘操作针对该轨；全局 Space、倍速和网格继续控制编辑工作台。也可用各轨的复制/粘贴按钮跨轨操作。“放入主轨”明确复制选中排列到主轨当前时间，草稿原排列保留。对照轨复制排列时去掉原歌曲的专属采样和源格式字段，避免错误引用另一首歌的文件。

hitsound 轨的采样输入必须是歌曲目录中的现存相对路径；不接受绝对路径或 `..`。目前提供自定义文件和逐键音量，完整采样组/附加音/继承试听仍在剩余清单中。

## 保存与恢复

轨道资料不写入 `.osu`。位于 `%LOCALAPPDATA%\SimpleManiaEditor\Preview\tracks\<谱面路径哈希>\`：

- `workspace.json`：主谱源路径、可读的轨道类型、名字、显示/同步状态、对照源路径、轨道排序/宽度、底板平移、主轨播放位置、独立视口及缩放。
- `<轨道ID>.mc`：可读的草稿或对照快照。
- `.previous`：每次替换前保留的上一份文件。

自动保存约两秒一次，只保存完成的编辑手势；Ctrl+S 和正常关闭也等待轨道保存。另存为会建立独立轨道副本，目标已有轨道或损坏资料时不覆盖。隐藏轨道不会删除资料。

若清单或快照读取失败，原文件留在目录中，编辑器拒绝覆盖。恢复前复制整个轨道目录作备份，可核对 `.previous` 后恢复；当前尚无自动回滚向导。突然终止仍可能丢失最近未落盘的改动，完整持久化 command 日志和版本树尚待完成。

这批轨道不播放独立音频，也不提供协作广播；音频轨、完整 hitsound 继承、更多轨道工具、官方/7K 难度算法在 [剩余清单](BACKLOG.md) 中。

## 底部事件时间轴

时间轴横向表示歌曲实际毫秒：红线为 BPM，绿线为 SV/采样事件，金色背景为 Kiai，金色短线为跳转书签。左键点击或拖动跳转，双击事件线编辑原生 Timing。Timing 标签及列表不接受右键删除；先左键选择，再按 Delete 或点击删除按钮。

全局难度已有 4K Rework 结果时显示结果，否则显示实验负荷；它与局部负荷都不是官方星级或 Sunny 7K。

0.1.17 顶部「显示 / 布局」可直接恢复全局栏、整理主轨及调整卡片。底板在内容尺寸计算完后应用期望位置，窗口缩放和轨道重建不再强制偏移到左侧空白。播放中的 UI 更新保留正在显示的位置。
