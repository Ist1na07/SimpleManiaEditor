# 0.1.30 · 倍速切换与同步编辑

播放中的倍速变更在旧流继续输出时提前准备，新流接在设备已经排队的旧音频后。时钟先按旧缓冲的实际倍率推进，再切换到新倍率；画面和音画校准使用实际播放倍率，避免准备期间先使用请求倍率，以及新流回到准备前时间所造成的追赶/停顿。连续切速会等待前一次旧缓冲接续完成，暂停状态调整倍速仍保持暂停，明确跳转仍使用所选目标。

修复NAudio字节底层float缓冲的清零范围：短读、曲末、失效按键音与多声道空白区域正确清零，避免旧声音残留或误清有效音频。保音高算法与既有静音区对齐策略保持原有参数。

中心对称下在单点上绘制LN，会把原单点及其原有精确对称点作为一组替换，正拉/反拉均适用；拖动预览中也隐藏将被替换的旧对称点，一次撤销恢复原来的两点。独立占用的音符保留，既有锁定保护继续生效。

同步草稿、参考和hitsound轨道的滚轮时间导航统一交给主轨，避免先按草稿BPM吸附再换算回主轨而偏离网格。主轨网格更改立即同步；取消同步的轨道仍独立滚动，编辑操作继续使用各轨道自己的Timing。

验证包含44.1/48k真实双声道解码与DSP、模拟持续输出、120ms慢解码准备、1/.1/.25/.5/2切换、播放线单调/实际倍率/无设备重建、暂停后切速恢复，以及原生WaveBuffer清零。正反向对称替换、历史原子性、不同BPM草稿/负拍/多分度滚轮均有回归。模拟输出不能替代声卡、屏幕和音乐听感验收。
