# 0.1.16：试玩独占、事件时间轴与全局/局部分析

- 点击试玩立即取消未完成的指针手势、锁定编辑区、停止编辑音乐和打击音时钟，之后才保存工作副本并交给官方宿主。取消待提交的滚轮 seek，排空先前的播放命令，使用明确的 Pause，防止编辑器和试玩同时发声。退出后解锁，编辑音乐保持暂停；失败路径也解锁。官方设置窗口采用同一机制。
- Windows 编辑器改用系统桌面合成优先路径，保留 GPU 渲染和以显示帧更新的播放画面。已移除低延迟直接交换链优先项；是否消除具体屏幕上的撕裂仍需真实设备验收。
- 网格、编辑/试玩倍速、浮动缩放、底板平移和谱面参数移除逐项恢复按钮；快捷键、外观、音频偏好和其他全局设置保留恢复功能。滚轮调整仍可用。
- 主编辑区 Timing 标签和右侧 Timing 列表均取消右键删除；擦除工具只擦按键。删除事件需先左键选择，再按 Delete 或点击删除。
- 整个编辑面板底部增加歌曲毫秒时间轴：BPM 红线、SV/采样事件绿线、Kiai 区段金色高亮、跳转书签、播放位置和时间刻度。左键点击/拖动定位，双击事件线打开原生 Timing 编辑弹窗；右键不会删除。未加载音频时按实际按键/事件范围显示，不采用编辑器额外预留的 32 拍空白。
- 左侧全局密度/全局难度固定，不随底板平移；可隐藏，在设置 → 全局分析中恢复，显示偏好持久化。密度旁提供添加/浏览跳转书签。全局难度使用已有 4K Rework 结果；没有结果时展示明确标注的实验负荷，尚未替代官方/Sunny 7K 算法。
- 新增的局部密度/局部难度轨依旧可拖动、隐藏、切换同步；采用 500 ms 滑动窗口和连续绘制，与主轨共享缩放/时间位置。正式键头计入，草稿不计入。分析在后台按谱面修改重算，最多 250,000 个局部采样；播放帧不遍历全部按键。

验证包含真实编辑器指针/键盘路径、模拟输出实际音乐/DSP 播放、试玩期间输入隔离、音乐与无音频时钟暂停、返回解锁、全局轨固定/隐藏/持久化、Timing 右键及擦除保护、Kiai 时间轴与毫秒定位、连续局部密度，以及原有皮肤、轨道、保存/恢复和 Timing 回归。屏幕撕裂、硬件延迟及手感仍由真实体验确认。

关闭旧窗口后运行根目录 `Start-Editor.cmd`。便携包：`dist/SimpleManiaEditor-0.1.16/`。
