# 0.1.10 皮肤工作流与固定工具栏修复

上一版提供了皮肤导入入口，但缺少独立的皮肤列表与可靠的选择生命周期。本版处理完整“导入、选择、预览、切换、关闭、重进”流程。

- 独立的“调整”栏移除。网格、缩放、倍速滑条合并到顶部固定工具栏容器，窄窗口中内部内容可滚动。只保留一个“试玩”，从当前位置立即开始，删除“测试”和“从此处”的重复按钮。
- 试玩设置分为“皮肤”“游戏”“按键”。Note 样式、宽/高、界面宽度、判定线和数字位置等手动外观选项全部移除。外观由皮肤决定，内置外观按统一的 480 高度基准缩放；旧 JSON 外观字段可读以保持迁移，不再控制试玩外观。
- 新增皮肤库 `skins/library.json`。添加单个皮肤目录、整个 osu! Skins 目录或导入 `.osk`，之后在持久化列表中切换。提供当前 K 数预览、加载状态、图片数量和重新加载入口。
- 选择先保存，再后台加载。加载中关闭窗口、快速切换、重进不会回写旧选择。损坏的可选声音不拒绝有效皮肤图片。失效目录保留选择并报告错误；保存失败明确提示。
- 初始化后立即接收设置修改，修复等待音频加载期间修改被丢弃的问题。已保存的试玩窗口方式优先于父编辑器全屏状态。
- 对照官方解析器支持同一 `[Mania]` 下多个 `Keys`、Keys 之前的字段、重复配置取首个、带扩展名的动画/高清素材、旧 `7K.ini` 等配置、UTF BOM 和本地旧编码。没有按键素材时明确提示回退。
- LN 尾采用官方相反方向和顶部时间锚定，HitPosition 采用官方 240–480 范围。

参考 LegacyManiaSkinDecoder、LegacyNotePiece、LegacyHoldNoteTailPiece 原文保存在 `third_party/osu/`，固定于 `7e25f111466f1b5648d86856e5737d852402effe`，MIT 许可随包分发。相关规则移植进 Avalonia，没有声称嵌入整个 osu.Framework 客户端。

验证：50 项核心回归；真实 Avalonia 皮肤下拉、预览、外观选项移除、皮肤库重进、加载中关闭、快速切换、损坏声音、失效目录、父窗口全屏、官方格式与 LN 尾像素定位；顶部调整与唯一试玩按钮；100k 裁剪及最终 ZIP 启动。
