# 0.1.20：编辑交互与音符文本代码

关闭旧窗口，双击根目录 `Start-Editor.cmd`。便携包位于 `dist/SimpleManiaEditor-0.1.20/`。

## 本轮修改

- 播放视图的精确位置及时同步到工作区；暂停于非网格位置后放置、删除、属性编辑、复制粘贴、撤销不会因界面刷新跳回旧位置。原生 osu 的负拍视图也可以保存恢复。
- 左侧仅保留选择、单键、长条、擦除四个基础工具。播放、停止、撤销、重做统一留在上方固定栏。
- 「中心对车」改名「中心对称」，放在左侧快捷编辑区。点击工具（F6），依次点击起点、终点，两次点击均吸附网格且不放音符。范围内绘制自动生成中心对称单键/LN，无需额外启用选项。上下边调整时间，左右边调整参与列；再次点击工具关闭，划定期间 Esc 取消。范围按当前会话/轨道独立保留，重启后重新划定。生成后的音符仍可独立编辑。
- 对称目标位置已有音符时跳过该对称音符，原位置正常绘制；自对称音符只添加一次。成对放置可一次撤销。
- 多选后右键音符删除选中整批，一次撤销恢复；空白右键仍取消选择。Timing 保留左键选择后删除的规则。
- Ctrl+C 将选中音符写入系统剪贴板，使用 `.osu` 的 `[HitObjects]` 单键/LN 行，加注来源键数。可复制到聊天软件分享，复制第三方提供的这些文本后 Ctrl+V 在当前播放位置粘贴。粘贴保持各音符及 LN 端点的毫秒距离；右侧 Note →「音符文本代码」导入则保留原始毫秒时间。支持原生 sample 字段；代码不携带音频资源。键数冲突、无效行、只读/锁定目标在修改前拒绝。

官方 lazer 的系统剪贴板复制行为是时间戳，音符数据在内部剪贴板中；此功能对齐 `.osu` 文件音符行格式，不声称能直接读取官方 Ctrl+C 的内部数据。编辑器内部的混合 Note/Effect 剪贴板仍保留。

## 验证

55 项核心规格、完整 UI 回归以及最终工作台检查，覆盖范围两点/拖边、单键与反向 LN、重合跳过、多选右键/撤销、精确暂停位置、系统剪贴板复制/外部文本粘贴、原始时间导入、原文件隔离和便携包启动检查。

本轮未改变官方游戏宿主的游玩逻辑。播放性能仍按 0.1.18 的限制记录，尚未达到稳定 180 FPS / 1% low 180。
