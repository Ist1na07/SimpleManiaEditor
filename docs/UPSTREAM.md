# 上游来源

应用源码源自 [LumaChartStudio-Client](https://github.com/cux-rn/LumaChartStudio-Client)，基线 commit 为 `b78bdf6d2a4461184a2b56d474dce6aa1680a09c`，客户端自有源码使用 MIT。

`src/` 保留原项目/namespace，方便核对和后续移植上游修复。首发选取 Windows、Core、Application、Online、Storage 与测试项目；Android/iOS hosts 暂不包含。

原许可、第三方 notices 和许可证文本保留于 `src/LICENSE`、`src/THIRD-PARTY-NOTICES.md` 与 `src/licenses/`，发布时一并携带。SimpleManiaEditor 的变更记录见 Git 和发布说明。
