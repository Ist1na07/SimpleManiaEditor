# 0.1.12：试玩预热与右侧设置

- 试玩设置、皮肤目录/.osk 导入、osu! 用户配置导入放到右侧「设置」栏首部，移除顶部试玩按钮的隐蔽右键菜单。
- 编辑器打开时在后台预热一个自有官方游戏进程。退出试玩只返回编辑器并隐藏游戏窗口；再次点击复用字体、着色器、皮肤和音频资源。空闲时静音、停止音乐并降低后台帧率。
- 游戏与编辑器通过继承的本地标准输入/输出管道通信，不开放网络端口，不连接现有 osu! 进程。关闭编辑器时通知退出；异常父进程退出导致管道关闭，也会退出游戏。游戏异常退出后下次点击重建。
- 为编辑器练习提供轻量进入屏幕，保留官方 Player、重试与高性能会话。省去选歌页固定 650 ms 入场动画及 500 ms 等待；结束游戏画面的进入动画，避免开始时缩小/渐显。
- 压缩过的资源缓存与谱面内容分离。音符、Timing、元数据修改只替换测试 .osu；使用官方导出模块的路径规范化结果。音频、图像、采样等文件变化使缓存失效；监控失败或共享/受保护目录会重新导出。原文件不写入。
- 相同音频通过官方 WorkingBeatmap.TryTransferTrack 复用；窗口切换允许自有子进程获得焦点，退出后激活编辑器。

实际 GPU 验证包括一个 PID 连续试玩、官方设置、完整自动演奏、退出/重进和关闭；缓存测试验证未保存的音符/Timing/元数据、起点切片、规范化资源冲突及音频变更。时间记录位于 `artifacts/resident-playtest/*/timings.json`，生产监督器的端到端测试单独输出点击至进入耗时。

热启动可以省掉完整客户端启动和选歌转场；首次打开客户端、第一次加载某谱面的大素材、未完成的预热、异常重建仍可能等待。常驻进程保留游戏资源并占用内存；不承诺所有歌曲和设备都能固定在一个毫秒值内进入。
